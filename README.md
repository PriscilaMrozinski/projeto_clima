1. Descrição

Aplicação web moderna e totalmente responsiva para consulta de previsão do tempo em tempo real, desenvolvida com HTML5, CSS e JavaScript.
Utiliza as APIs Open-Meteo (Geocoding e Weather Forecast) para fornecer informações detalhadas sobre o clima do dia atual e dos 4 dias seguintes, em qualquer cidade do mundo.

<br />

2. Funcionalidades

Busca inteligente de cidades

Informações em tempo real:

Condição do tempo

Temperatura atual, máxima e mínima

Previsão de 4 dias

Tema automático (dia/noite)

Design totalmente responsivo

Tratamento de erros e timeout

Interface intuitiva com ícones meteorológicos

6. Como Executar
Método 1 — Abrir no navegador

Abra o arquivo index.html

Método 2 — Live Server (recomendado)

Instale a extensão no VS Code

Clique com o botão direito → Open with Live Server

<br />


7. Como Usar

Digite a cidade

Pressione Enter ou clique em "Buscar"

Veja as informações detalhadas e a previsão dos próximos dias

Clique no botão 🏠 para nova busca
